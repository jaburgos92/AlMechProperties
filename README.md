# AlMechProperties
HarvardX PH125.9x Data Science Capstone: Predicting Mechanical Properties of Aluminum Alloys

The second capstone project as part of the HarvardX Professional Certificate in Data Science is to utilize R for applying machine learning techniques on a publicly available dataset to solve an open-ended problem of choice. 

The chosen problem is to use reported elemental composition and processing condition combinations for a variety of unique aluminum-based alloys to help predict what mechanical properties would be when presented with a new hypothetical aluminum alloy. The three mechanical properties of interest are tensile strength, yield strength, and elongation. Three models independently predict each property using only the composition and processing data.

This repository contains 3 files:

.pdf report outlining how models for predicting tensile strength, yield strength, and elongation were developed and what the results were
.Rmd file that was the source for creating the .pdf file
.R file with only the code used within the .Rmd file
